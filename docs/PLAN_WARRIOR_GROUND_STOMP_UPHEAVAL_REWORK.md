# [구현 계획서] 전사 지면강타 $\rightarrow$ 디아블로4 야만용사 [지각변동(Upheaval)] 스타일 방향성 지진 충격파 개편

## 1. 목적
- 전사 스킬 '지면 강타'를 기존의 단순 플레이어 중심 원형 장판에서, **디아블로4 야만용사의 [지각변동 (Upheaval)]** 처럼 목표 방향으로 **땅이 파파팍! 솟구치며 앞으로 뻗어나가는 연속 지진 지열 충격파**로 전면 개편합니다.
- 레벨에 따라 줄기 수가 확장됩니다:
  - **LV 1~2**: 1줄기 (정면)
  - **LV 3~4**: 2줄기 (부채꼴 2갈래)
  - **LV 5**: 3줄기 (정면 + 좌우 3갈래 대형 지각변동)
- 샌드박스 메뉴에서 대미지, 사거리(길이), 폭발 반경, 줄기 수, 쿨다운, 카메라 셰이크를 실시간 튜닝할 수 있도록 연동합니다.
