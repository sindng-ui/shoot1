# 💨 플레이어 대시(Dash) 스킬 및 샌드박스 튜닝 구현 계획서

## 1. 개요 및 요구사항
- **조작**:  키 입력 시 대시 발동.
- **쿨타임**: 기본 5.0초.
- **물리 동작**: 미끄러지듯이 쭈우우~ 이동 (초반 급가속 후 후반 부드러운 Ease-Out 감속 제동).
- **시각 연출**: 지나간 궤적에 3~5개의 반투명 고화질 잔상(Ghost Trail) 생성 및 페이드아웃.
- **샌드박스**: 쿨타임, 이동 거리, 지속 시간, 가속/감속 커브 실시간 슬라이더 연동.
