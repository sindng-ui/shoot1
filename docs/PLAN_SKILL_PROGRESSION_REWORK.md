# [스킬 시스템 전면 개편] 레벨업 시 확실한 시각적/체감적 성장 리턴 극대화 계획

## 1. 🏹 궁수 스킬
- **관통 화살 (`bow`)**: 레벨당 화살 +1발 추가 (Lv1: 1발 ➡️ Lv5: 5발 전방 부채꼴 전멸 사격)
- **칼바람 글레이브 (`glaive`)**: 투척 글레이브 수 증가 (Lv1: 1개 ➡️ Lv5: 4개) + 사거리 9m ➡️ 13m 확장
- **화살 비 (`arrow_rain`)**: 레벨당 지속시간 +0.5s 증가 (Lv1: 1.5s ➡️ Lv5: 3.5s) + 반경 2.0m ➡️ 3.8m + 화살 20발 ➡️ 60발 폭증

## 2. 🛡️ 전사 스킬
- **대검 베기 (`slash`)**: 베기 각도 150도 ➡️ 270도 + 사거리 2.5m ➡️ 4.8m 거대 황금 검기
- **지면 강타 (`ground_stomp`)**: 지진 충격파 반경 1.8m ➡️ 4.2m + 바위 파편 수 8개 ➡️ 24개 폭증
- **휠윈드 (`whirlwind`)**: 회전 검기 반경 2.2m ➡️ 4.0m + 4연타 연속 참격

## 3. 🧙‍♂️ 마법사 스킬
- **화염구 (`fireball`)**: 화염구 발사 수 1발 ➡️ 3발 + 폭발 반경 1.6m ➡️ 3.2m 거대 화염 폭발
- **서리 폭발 (`frost_nova`)**: 냉기 파동 반경 2.8m ➡️ 5.2m 화면 절반 빙결 + 오한 지속시간 3.5s ➡️ 6.5s
- **연쇄 번개 (`chain_lightning`)**: 연쇄 전이 횟수 4회 ➡️ 8회 + 점프 사거리 4m ➡️ 6.5m

## 4. ⚔️ 공용 스킬
- **오비탈 블레이드 (`orbital`)**: 칼날 수 2개 ➡️ 6개 + 회전 반경 & 회전 속도 증가
