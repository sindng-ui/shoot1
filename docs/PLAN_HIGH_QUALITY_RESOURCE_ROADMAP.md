## 📌 Phase 1: 하단 3단 메인 HUD 전면 개편 (상세 계획)

### 1. 화면 최하단 EXP 프로그레스 바 (10칸 분할)
- **위치**: 화면 최하단 밀착 (`y = 0`, 전체 너비 `1920px` 또는 중앙 `1600px`)
- **디자인**:
  - 10개의 명확한 세그먼트(10% 단위 구분 눈금선)가 들어간 다크 메탈 슬롯 베이스.
  - 경험치 획득 시 황금빛/에메랄드빛 부드러운 그라데이션 게이지가 차오름.
  - 좌측 끝: 판타지 다이아몬드/방패 모양의 황금빛 레벨 배지 (`17`).
  - 우측 또는 중앙: `EXP 1,250 / 2,000 (62.5%)` 깔끔한 텍스트.

### 2. 중앙 스킬 슬롯 & 시계방향 쿨타임 회전
- **위치**: EXP 바 바로 위 중앙 정렬 (`y = 48px ~ 110px`)
- **디자인**:
  - 6개의 액티브 스킬 슬롯 (`48x48px` 또는 `52x52px`)이 골드/다크스틸 프레임으로 가로 정렬.
  - **시계 방향 쿨타임 표시 (Radial 360° Clockwise Fill)**:
    스킬 발동 시 `Image.Type = Filled`, `Fill Method = Radial 360` 어두운 반투명 오버레이가 시계 방향으로 줄어들며 쿨타임 잔여 시간을 직관적으로 표시!
  - 각 스킬 아이콘 하단: `Lv. 1`, `Lv. 2`, `Lv. 3` 골드 텍스트 뱃지.
  - 슬롯 좌측: 대시/회피 전용 슬롯 (`Space 👟`).

### 3. 스킬 슬롯 상단 엠블럼 플레이어 HP 게이지
- **위치**: 스킬 슬롯 바로 위 중앙 (`y = 118px ~ 155px`)
- **디자인**:
  - 중앙에 멋진 투구/바이킹 뿔/전사 문양 엠블럼 뱃지.
  - 엠블럼을 중심으로 좌우로 펼쳐지는 와이드 체력바 (`500px` 너비).
  - 강렬한 루비 레드 체력 게이지 + 피격 시 즉시 줄어들지 않고 서서히 줄어드는 고스트 화이트 잔상 게이지 (Juice).
  - 중앙 텍스트: `1000 / 1000` (굵고 선명한 폰트).
