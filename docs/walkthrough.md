# 🧪 샌드박스: 경험치 대비 몹 젠 비율(% 단위) 입력 및 파일 저장/로드 완료

형님! 요청해주신 **레벨업 시 늘어나는 경험치 대비 몬스터 젠 비율을 0% ~ 100% 정수 단위로 샌드박스에서 직접 입력/조절하고, [파일에 저장] 버튼 클릭 시 JSON 파일로 완벽하게 영구 저장 및 복원되는 시스템** 연동을 완료했습니다!

---

## 🎯 주요 개선 및 동작 사항

1. **직관적인 퍼센트(%) 슬라이더 & 수치 입력 (`SkillTuningRowConfigurator.cs`)**:
   - 샌드박스의 **[시스템] ➔ [경험치/레벨업 튜닝]** 탭:
     - `📊 경험치 증가분 대비 몹 젠 비율 (%: 0~100%)`
     - **0%부터 100%까지 1% 단위**로 정밀하게 슬라이더 조절 및 수치 확인 가능 (기본값: **`30%`**).

2. **완벽한 JSON 파일 영구 저장 & 로드 (`SkillConfigRepository.cs`, `SkillTuningPersistenceHelper.cs`)**:
   - 우측 하단의 **[💾 파일에 저장]** 버튼을 누르면:
     - `Application.persistentDataPath/skill_configs.json` 파일 및 `PlayerPrefs`에 `MobScalingRatio` 수치가 영구 저장됩니다.
   - 게임 재시작 시에도 저장된 `%` 수치가 자동으로 로드되어 인게임 몬스터 스폰에 즉시 적용됩니다.
   - **[🔄 기본값 복원]** 버튼 클릭 시 기본값인 30%로 초기화됩니다.
