# [궁극기 리워크] 폭풍의 활: 5초 쿨다운 & 디아블로2 '축복의 망치' 나선 회전 도입 계획

## 1. 쿨다운 5.0초 변경
- 5초마다 1회 강력한 태풍 화살 폭풍 발동

## 2. 디아블로2 축복의 망치(Blessed Hammer) 나선 궤적 (Archimedean Spiral)
- 8발의 태풍 관통 화살이 플레이어 중심에서 생성
- 각도: theta(t) = theta_0 + omega * t (초당 2~3회전)
- 반경: r(t) = v_expand * t (0.5m -> 8.5m 화면 전체로 팽창)
- 지나가는 모든 적을 무제한 관통 분쇄
