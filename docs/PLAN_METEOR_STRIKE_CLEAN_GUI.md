# [메테오 스트라이크] 대미지 범위 경계선(GUI 인디케이터) 및 효과 크기 컴팩트 최적화 계획

## 개요
1. **대미지 범위 경계선 부재**: 착탄 전/착탄 순간에 실제 대미지가 들어가는 반경(2.8~3.0m)을 명확하게 표시하는 **원형 타겟 경계선 인디케이터(AOE Decal & Countdown Ring)** 구현
2. **과도하게 큰 폭발 스케일 축소**: 화면 전체를 가리던 폭발 스케일(15m+)을 **실제 대미지 반경(반경 2.8m / 직경 5.6m)에 1:1로 일치**시키고 날렵하고 깔끔한 GUI/VFX로 리파인
