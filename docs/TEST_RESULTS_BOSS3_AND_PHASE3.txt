5. BUG FIX & RESOLUTION: LICH KING (BOSS 3) VICTORY TRIGGER
--------------------------------------------------------------------------------
[FIXED] MonsterEntity.IsBoss property:
        - Originally: `public bool IsBoss => Type == MonsterType.Boss;`
        - Bug: Boss3 (MonsterType.Boss3) evaluated to IsBoss == false!
        - Consequence: BossSpawnedEvent was not fired (no boss HP bar) and BossDiedEvent
          was NEVER dispatched upon Lich King's death, preventing the victory sequence.
        - Fixed to: `public bool IsBoss => Type == MonsterType.Boss || Type == MonsterType.Boss3;`
[FIXED] MonsterSpawnerView.OnBossDied Fallback:
        - Added multi-condition matching (evt.BossName == "Arch-Lich Malakar" || evt.BossName.Contains("Lich") || _spawnedBoss3)
        - Guarantees StageVictoryUiView is triggered 100% reliably regardless of exact name string.
[FIXED] StageVictoryUiView.ShowVictoryPopup:
        - Added `_panelRoot.transform.SetAsLastSibling()` to ensure victory popup is brought to the absolute front of the UI hierarchy.
