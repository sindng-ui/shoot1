# 📱 모바일/PC 통합 UI 및 폰트 대형화(Scale-Up) 구현 계획서

## 1. 개요 및 원인
- 기존 1920x1080 캔버스 스케일러로 인해 6인치 스마트폰에서 글씨와 UI가 쌀알처럼 작게 보이는 문제.
- 기준 해상도를 1440x810으로 최적화하여 전체 UI를 약 35% 자연 확대하고,
- 체력바, 스킬 슬롯, 레벨업 카드, 타이머, 자원 텍스트의 폰트 및 슬롯 크기를 30~50% 상향 조정.

## 2. 파일 수정 계획 (500줄 준수)
- : 1440x810 기준 해상도 전환, 슬롯 44->56, 체력바 높이 20->30, 폰트 대형화 (~430줄)
- : 슬롯 뱃지 및 폰트 크기 상향 (~145줄)
- : 1440x810 전환, 카드 크기 240x360 -> 280x420, 폰트 확대 (~435줄)
- , , : 기준 해상도 전환 및 폰트 확대
